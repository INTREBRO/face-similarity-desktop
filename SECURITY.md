# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it by:

1. **Do NOT** open a public GitHub Issue
2. Send an email to the project maintainer describing the issue
3. Allow time for the maintainer to respond and fix the vulnerability
4. Once the fix is released, you may disclose the vulnerability publicly

## Security Best Practices

When contributing to this project:

- Do not commit API keys, tokens, or secrets
- Do not commit large model files (handled via `.gitignore`)
- Report any potential security issues before creating a PR
