# Contributing to face-similarity-desktop

Thank you for your interest in contributing!

## Development Setup

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/face-similarity-desktop.git
   cd face-similarity-desktop
   ```

3. Install dependencies:
   ```bash
   npm install
   cd python-server && pip install -r requirements.txt
   ```

4. Run in development mode:
   ```bash
   npm start
   ```

## Code Style

- Use 2 spaces for indentation
- Use descriptive variable and function names
- Add comments for complex logic
- Keep functions small and focused

## Pull Request Process

1. Create a new branch for each feature or fix
2. Make your changes and commit with clear messages
3. Ensure the app runs without errors
4. Submit a PR with a clear description of the changes

## Reporting Issues

- Use the GitHub Issues page
- Include your OS version, Electron version, and Python version
- Provide steps to reproduce the issue
- Attach screenshots if applicable
